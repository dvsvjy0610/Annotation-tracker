# Annotation Tracker
1. Install PostgreSQL, create DB + tables (see top of schema.sql)
2. `pip install -r requirements.txt`
3. Edit DB credentials in app.py
4. `python app.py` -> open http://127.0.0.1:5000
5. Click "Import clips CSV" and upload sample_clips.csv (watch Pandas clean it: 3 good rows kept)
